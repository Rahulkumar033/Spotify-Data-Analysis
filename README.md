# Spotify Music Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on Spotify music datasets to identify trends in song popularity, genres, audio features, and listener preferences.

## Objectives

- Clean and preprocess Spotify datasets
- Perform Exploratory Data Analysis (EDA)
- Analyze audio features such as danceability, energy, tempo, and valence
- Visualize trends using interactive charts
- Study genre popularity and song characteristics

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Google Colab

## Key Insights

- Most popular songs have moderate to high danceability and energy.
- Song popularity has increased over time.
- Energy and loudness are positively correlated.
- Different genres show diverse popularity trends.
